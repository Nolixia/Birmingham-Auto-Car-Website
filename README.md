# Birmingham Auto Care

Standalone Next.js website with responsive pages, repeating scroll animations,
mobile navigation, booking form, and WebP-only photographic assets.

This version does not require any additional hidden configuration directory.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production build

```bash
npm run build
npm run start
```

Requires Node.js 22 or newer.
